# VocaDev Miku Dark VS Code Theme

A sleek, dark VS Code color theme inspired by Vocaloid Hatsune Miku (初音ミク).

## Palette
- **Primary (Miku Cyan):** `#39C5BB`
- **Secondary (Light Cyan):** `#86CECB`
- **Accent (Neon Green):** `#39FF14`
- **Dark Navy:** `#1A1A2E`
- **Background:** `#0F0F23`
- **Foreground:** `#E0E0E0`

## Features
- Carefully calibrated dark background for low eye strain.
- Glowing cyan and neon green highlights.
- Clear syntax highlighting for languages such as TypeScript, JavaScript, Python, HTML/CSS, and JSON.
- Terminal and Git diff colors matching Miku's color aesthetic.
