# VocaDev Miku Dark - JetBrains Theme

A developer customization theme inspired by Hatsune Miku (初音ミク) for JetBrains IDEs.

## Features
- **Miku Primary Accent**: `#39C5BB`
- **Background**: `#0F0F23`
- **Foreground**: `#E0E0E0`
- Custom editor syntax highlighting and UI styling.

## Supported IDEs
- IntelliJ IDEA
- PyCharm
- WebStorm
- Android Studio
- CLion / Rider / GoLand / PhpStorm / RubyMine

## Installation

1. Download the built zip file (`vocadev-jetbrains-theme-0.1.0.zip`) from releases or build locally.
2. In your JetBrains IDE, open **Settings / Preferences** (`Ctrl+Alt+S` or `Cmd+,`).
3. Select **Plugins**, click the gear icon ⚙️, and select **Install Plugin from Disk...**.
4. Choose the plugin `.zip` file and restart the IDE.
