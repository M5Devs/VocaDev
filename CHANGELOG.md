# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-08-25

### Added
- Monorepo setup using `pnpm` workspaces and `Turborepo`.
- `@vocadev/core`: Color palette definitions for Hatsune Miku (`#39C5BB`), with TypeScript exports, JSON schemas, and CSS variables.
- `@vocadev/vscode-theme`: VS Code dark theme for Hatsune Miku featuring custom UI styling, syntax highlighting, terminal colors, and diff styling.
- `@vocadev/ui`: Placeholder package for Phase 3 UI component development.
- GitHub Actions workflows for PR linting/testing and auto-publishing to VS Code Marketplace on release.
